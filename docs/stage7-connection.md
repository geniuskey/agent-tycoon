# 7단계 연결 — 설계

> 상태: 설계 확정, 구현 완료

## 한 줄 요약

7단계 자유 플레이 미션 3개(DRAM Retention, 설비 대시보드, 회의 요약)는 지금 캠페인과 끊겨 있다.
0–6단계에서 만든 **조직의 기반**(표준·권한·지식·Agent 운영 원칙)을 **사내 공통 지침(AGENTS.md)** 으로 이어 받아,
"기반이 갖춰진 조직에서는 같은 일이 이렇게 달라진다"를 체험하게 한다.

## 이야기

세 미션은 같은 Nova Semiconductor의 다른 팀이다. 수율팀에서 정착한 방식이 사내 표준이 되어,
다른 팀의 Agent도 시작할 때 **사내 공통 지침 `/org/AGENTS.md`** 를 읽는다.
지침에 들어간 원칙은 Agent가 **추천**한다 — 판단 지점에서 좋은 쪽을 짚어 주고, 프롬프트 카드의 해당 조건에 '사내 지침 추천'이 붙는다. 결정은 여전히 플레이어가 한다.
**캠페인에서 놓친 원칙은 지침에 없다** → 그 판단은 추천 없이 플레이어가 직접 해야 한다.

## 캠페인 결과 → 사내 지침 → 7단계 효과

| 원칙 id | 캠페인 조건 (이월 플래그) | 사내 지침 한 줄 | 7단계에서 Agent가 추천하는 것 |
|---|---|---|---|
| time | 2단계 시각 합의 (`agenda.time` · `time.utc`) | 저장 UTC · 표시 KST. 로거별 시간대를 먼저 확인 | 설비 대시보드: 프롬프트 조건 '로거별 시간대 확인' |
| db | 3단계 AI 최소 권한 (`access.ai.mart_ro`) 또는 6단계 위험 도구 제외 (`tools.safe`) | 운영 DB 직접 조회·공용 계정 금지 | 설비 대시보드: 조건 '공용 계정·운영 DB 금지', 데이터 소스 판단에서 export |
| quality | 3단계 품질 규칙 통과 (`mart.checks_pass`) | 분석 전에 단위·코드·키 정합성 검사 | DRAM: 조건 '측정 단위 확인', 단위 불일치 판단에서 변환 |
| hypo | 4·5단계 가설 원칙 (`kb.hypo_rule` · `kb.cause` · `eval.q6`) | 원인은 단정하지 않고 가설 + 확인 담당자 | DRAM: 조건 '가설로', 원인 결론 판단에서 가설 |
| access | 3단계 AI 최소 권한 (`access.ai.mart_ro`) | 권한 밖 데이터는 우회하지 않고 요청 절차로 | DRAM: 조건 '고객·출하 정보 제외', 권한 없는 데이터 판단에서 내부 데이터만 |
| sensitive | 4단계 민감 정보 제외 (`eval.q7`) | 대외비·개인 평가 정보는 AI 산출물에 넣지 않음 | 회의 요약: 조건 '대외비 제외', 대외비 판단에서 제외 |
| external | 6단계 운영 전환 (`golive.go` · `spec.human_review`) | 외부 발송·게시는 사람 검토 후, 외부 수신자 기본 제외 | 회의 요약: 조건 '외부 협력사 제외', 수신자 판단에서 내부만 |

지침으로 **막을 수 없는 판단**은 그대로 남는다: 설비 대시보드의 알람 기준(회의록 근거), 회의 요약의 담당자 불명확, DRAM 분석 결과의 교차 검증.
"기반은 반복되는 실수를 없애 주지만, 새 판단은 여전히 사람의 몫"이라는 메시지.

## 화면

- 홈 7단계 카드: 캠페인 6단계를 마쳤으면 "사내 공통 지침 — N개 원칙 (캠페인 결과)"을 보여주고, 미션 상세에서 **기반 있이 / 기반 없이** 중 골라 시작
- 미션 안: `/org/AGENTS.md` 파일과 페이지(`sim://org/agents`). Agent가 일을 시작할 때 `Read(/org/AGENTS.md)` 로그
- 피드백: 원칙마다 "사내 지침을 활용했습니다" / "추천을 따르지 않았습니다"

## 결정 사항 (2026-11-23)

1. 시작 방식: **항상 기반 있이** — 캠페인에서 가장 멀리 간 제출 기록의 이월 상태로 지침을 만든다. 캠페인을 안 했으면 지침 없음
2. 지침 강도: **추천만** — 판단 지점은 그대로 나오고, Agent가 지침을 근거로 좋은 쪽을 추천한다
   (로그 `📘 사내 지침에 따라 추천`, 선택지·프롬프트 조건에 `📘 사내 지침 추천` 표시). 따르면 평가에 긍정, 따르지 않으면 지적

## 구현

- 시나리오 `foundation: [{ id, when, text, from }]` — `when`은 캠페인 이월 플래그 기준. 참이면 `org.<id>` 플래그와 `/org/AGENTS.md`
- 선택지 `recommendedBy`, 프롬프트 조건 `recommendedBy` — 원칙 id
- 자유 플레이 미션에는 캠페인 회사 상태(플래그·파일)를 그대로 섞지 않는다 (지침으로만 이어 받음)
- 홈 미션 상세: 원칙별로 켜짐/꺼짐(캠페인에서 만들지 못함)을 보여준다
