### 브라우저 실제 플레이 점검 (2026-11-25)

헤드리스 Chrome으로 0→6단계와 7단계 연결(사내 공통 지침 추천)을 화면에서 직접 진행했다 (선택 카드·메신저·회의실·plan mode 클릭, 일부는 터미널 명령). 모든 단계가 결과 기준을 충족했고, 발견해서 고친 것:

- 피드백의 신뢰도 목록에서 이번 미션에 없는 인물이 내부 ID(`park`)로 표시됨 → 전체 시나리오에서 이름을 찾음
- Agent 패널이 3개 이상일 때 지시 카드의 하단 버튼 줄이 줄바꿈되며 선택지를 가림 → 버튼 줄바꿈 금지, 좁은 패널에선 단축키 안내 숨김, 지시 카드 최대 높이 55%→60%
- 새로고침하면 가상 시간이 마지막 명령 시점으로 되돌아가고, 직전에 연 화면 확인 기록이 사라짐 → 작업 상태 변화·Agent 질문·답장·화면 확인 때도 세션 저장
- 2단계 '지난 주차도 같은 기준으로 재계산' 조건을 줘도 Agent 로그가 "W45는 예전 계산"이라고 말함 → 조건에 따라 로그 분기
- 홈 자유 플레이 '플레이 가능 10'이 캠페인 미션까지 셈 → 자유 플레이 미션만(3)
- 타임라인에서 `data-engineer` 같은 긴 Agent 이름이 잘림 → 이름 칸 확대
- 피드백 표기: '자연어 N' → 'Agent 지시 N' (선택 카드 지시도 포함되므로), Agent 1개일 때 "1개 Agent가 업무를 나누어" 문구 수정

남은 관찰 (미수정): 2×2 패널에서 결정 카드가 열리면 Agent 로그가 한두 줄로 줄어듦, 5단계 마트 화면에 W51 시점에도 W52 행이 보임.

## 수직 기능 (첫 번째 완성형 흐름)

업무 선택 → Agent 생성 → CLI/자연어 지시 → 상태 변화 → 가상 산출물 확인 → 오류 발견·수정 → 제출 → 학습 피드백 → 이력 복기.
세 시나리오 모두 이 흐름을 끝까지 지원하며 `tests/*.test.ts`에서 정상/실패/복구 경로를 자동 검증한다.
