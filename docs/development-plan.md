## 수직 기능 (첫 번째 완성형 흐름)

업무 선택 → Agent 생성 → CLI/자연어 지시 → 상태 변화 → 가상 산출물 확인 → 오류 발견·수정 → 제출 → 학습 피드백 → 이력 복기.
세 시나리오 모두 이 흐름을 끝까지 지원하며 `tests/*.test.ts`에서 정상/실패/복구 경로를 자동 검증한다.

## 다음 단계

### 단기 (Phase 4 확장)
1. 카탈로그 시나리오를 우선순위대로 구현: MCU 펌웨어 VOC(SW 이슈) → NAND Vt 분포(분석) → FPGA Timing(설계 검증) → HBM 적층 수율 → 나머지
2. 시나리오 공통 패턴 추출: "데이터 검증 gate", "교차 검증 Task", "보안 gate", "QA 게이트 배포" 스니펫 문서화
3. `gen-data.mjs`를 도메인별 생성기 모듈로 분리 (wafer map, 시계열, 로그, 분포)
4. 시나리오 작성용 JSON Schema 파일 제공 (에디터 자동완성)

### 중기
- 시나리오 편집기(웹 UI) 및 미리보기
- 브라우저 뷰 추가: 이슈 트래커, 코드 diff 리뷰, 회로/파형 뷰어
- 토큰 비용/시간 예산(선택 옵션) 및 난이도 조절
- Agent 간 메시지(협업) 이벤트 확장, Agent 컨텍스트 한도 시뮬레이션

### 장기 (온프레미스 서버 추가 시)
- 학습 이력 통합, SSO, 관리자 대시보드(조직별 학습 현황)
- 시나리오 배포 파이프라인 (검증 → 승인 → 배포)
