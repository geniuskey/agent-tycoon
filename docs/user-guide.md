# 사용자 가이드

> Agent Tycoon은 **시뮬레이션**입니다. 실제 AI는 동작하지 않으며, 모든 회사·데이터·인물은 가상입니다.

## 1. 시작
1. 홈에서 제품 영역 / 직무 / 업무 유형으로 시나리오를 고릅니다.
2. 브리핑(요청자, 목표, 완료 조건, 산출물, 학습 목표)을 읽고 **업무 시작**.
3. 난수 시드는 그대로 두면 됩니다. 같은 시드 + 같은 명령 순서 = 같은 결과.

처음이라면 **회의 요약 및 Action Item 정리**(난이도 ●○○, 약 10분)를 추천합니다.

## 2. 화면
| 영역 | 내용 |
|---|---|
| 상단 | 가상 시각(1 tick = 1분), 속도(❚❚/1x/2x/4x), 개입 필요 수, 브리핑·힌트·제출 |
| 왼쪽 | Task 목록(상태·담당·진행률·선행 Task), Agent 목록(상태, 대기 사유). Agent 클릭 → 전용 터미널 |
| 가운데 | 멀티 터미널. `orchestrator` 셸 + Agent별 세션. 하단: 타임라인(Gantt)·알림·이벤트 로그 |
| 오른쪽 | 가상 브라우저(`sim://`), 파일 탐색기, 미리보기(버전·변경 비교) |

## 3. 기본 흐름
```text
❯ roles                         # 생성 가능한 역할
❯ task graph                    # 업무 구조와 병렬 가능 단계
❯ agent spawn analyst           # Agent 생성 → 전용 터미널 열림
analyst ❯ 데이터 품질부터 검증해줘   # Agent 터미널에서 자연어 지시
❯ @domain-expert 공정 이력 정리해줘  # 셸에서 @로 지정
```
- Agent가 **Waiting/Blocked**(⏸)가 되면 Agent 터미널에 번호나 자연어로 답하세요. 답하기 전까지 진행하지 않습니다.
- **Failed**면 실패 로그의 원인을 해결한 뒤 `agent retry <agent>`.
- 산출물은 `open sim://…`, `cat <file>`, 파일 탭에서 직접 확인하세요. 확인 행동도 평가됩니다.
- 끝나면 `submit` (필수 Task 미완료 시 `submit --force`).

## 4. 명령 요약
| 명령 | 설명 |
|---|---|
| `agent spawn/list/status/assign/logs/inspect/reply/interrupt/resume/retry/restart/handoff/kill` | Agent 관리 |
| `task list / show <id> / graph` | 업무 구조 |
| `ls`, `tree`, `cat`, `diff`, `open`, `pages` | 가상 파일·브라우저 |
| `brief`, `hint`, `help`, `clear`, `submit` | 기타 |

자연어 공통 지시: "진행 상황 알려줘", "작업 멈춰", "계속 진행해", "다시 시도해", "analyst에게 넘겨".
인식하지 못한 지시는 실행되지 않고 지원 예시가 안내됩니다.

## 5. 단축키
| 키 | 동작 |
|---|---|
| Tab | 자동완성 |
| ↑ / ↓ | 명령 이력 |
| Ctrl+F | 패널 로그 검색 |
| Ctrl+L / Ctrl+C / Ctrl+U | 화면 지우기 / 입력 취소 / 줄 지우기 |
| Alt+1..9 | 패널 이동 |
| Alt+Enter | 패널 최대화 토글 |

## 6. 피드백과 복기
제출하면 요청자 반응(결과 기준)과 9개 차원(업무 분해, 배정, 병렬, 검증, 오류 대응, 중복, 도메인, 근거, 보안)의 구체적인 피드백을 받습니다.
**작업 이력 복기** 탭에서 슬라이더로 임의 시점의 Agent/Task 상태를 다시 보고, 내 판단 기록과 이벤트 로그를 확인할 수 있습니다.
홈의 작업 이력에서 세션을 이어하거나 JSON으로 내보낼 수 있습니다. 진행 상태는 브라우저(IndexedDB)에 자동 저장되며 새로고침해도 복구됩니다.
