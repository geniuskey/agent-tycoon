# 요구사항서 — 설비 이상 감지 대시보드 (v0.3 초안)

- 요청: 생산기술팀 설비파트 오세린 프로
- 작성일: 2026-11-18
- 상태: **초안 (일부 항목 미확정)**

## 배경
야간/주말에 chamber 압력 이상이 늦게 발견되는 일이 반복되고 있다. 설비 엔지니어가 한 화면에서
설비별 chamber pressure 추이와 이상 알람을 확인할 수 있는 대시보드가 필요하다.

## 기능 요구사항
1. 설비별 chamber pressure 시계열 차트 (대상: ETCH-03, ETCH-07, DEP-02, CMP-01)
2. **설비 선택 필터** — 특정 설비만 보기
3. 이상 알람 목록 (시각, 설비, 측정값, 기준)
4. 정비 이력 표시
5. 모든 시각은 **KST** 기준으로 표시

## 이상 판정 기준
- 이상 판정 기준은 **11/18 회의에서 논의한 기준을 적용**한다. (예: 50 mTorr 초과 시 알람)

## 데이터
- `/data/sensor_log.csv` — 설비 센서 로그 export (10분 간격, 1일치)
- `/data/maintenance_log.csv` — 정비 이력

## 비기능
- 사내망 전용, 외부 라이브러리 CDN 사용 금지
- 운영 DB 직접 연결은 정보보호팀 승인 후 별도 진행 (이번 범위는 export 파일 기반)
