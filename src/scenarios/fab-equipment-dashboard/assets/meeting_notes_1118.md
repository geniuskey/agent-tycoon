# 회의록 — 설비 모니터링 대시보드 킥오프

- 일시: 2026-11-18 (화) 15:00–15:40
- 참석: 오세린(생산기술), 박도현(설비 ETCH), 임가은(설비 DEP), 정우진(IT)

## 논의 내용
1. **알람 기준**
   - 박도현: 설비마다 정상 압력 수준(base)이 다르다. DEP-02는 평소 55 mTorr 근처라 고정값 50이면 하루 종일 알람이 뜬다.
   - 임가은: 고정 임계값보다는 **설비별 SPC 관리한계(평균 ± 3σ)** 로 가자.
   - 결론: **설비별 SPC 관리한계(평균±3σ, 정상 구간 기준) 적용.** 요구사항서 예시값(50)은 이전 안이므로 무시.
2. **데이터**
   - 정우진: 센서 로그 export는 설비 로거마다 시간대 설정이 다르다. **ETCH 계열 로거는 UTC** 로 찍힌다. `tz` 컬럼 확인 필요.
   - 운영 MES DB 직접 조회는 정보보호팀 승인 전까지 불가. 이번에는 export 파일 사용.
3. **필터**
   - 설비 엔지니어는 담당 설비만 보는 경우가 많아 설비 필터가 필수.
