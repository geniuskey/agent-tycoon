# 주간보고_v7_최종.xlsm — 숨은 계산 규칙 (박서준 선임 구술, AI 어시스턴트 정리)

> 이 규칙들은 **어떤 문서에도 없고 매크로 안에만** 있습니다.

1. **재측정 lot**: 같은 lot이 두 번 측정되면 첫 번째 측정값은 버리고 두 번째만 사용
   - 안 하면 수율이 2~3%p 낮게 나옴
2. **엔지니어링 lot 제외**: lot ID가 `E`로 시작하면 수율 계산에서 제외
3. **불량 Top5 집계**: 검사실 엑셀의 '합계' 열이 아니라 코드별 열을 직접 더함 (합계 열이 가끔 틀림)
4. **다운타임 영향**: 설비팀 메일의 정지 시간 × 0.08%p/h (박 선임 경험치, 근거 문서 없음)
