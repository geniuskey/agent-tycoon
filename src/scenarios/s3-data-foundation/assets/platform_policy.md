# 데이터플랫폼팀 운영 정책 (발췌)

1. **운영 MES DB 직접 조회 금지.** 원천은 IT가 제공하는 일 배치 export(매일 02–04시)를 사용한다.
2. 테이블 이름: `<계층>.<영역>_<대상>` (예: `mart.equipment_event`). 계층: `raw` → `mart`.
3. **실패한 행은 버리지 않는다.** `quarantine.*` 테이블에 사유와 함께 격리하고 오너에게 알린다.
4. 운영 이관 조건: 품질 검사 통과, 데이터 오너 승인, 카탈로그 등록.
5. 개인정보 매핑 키(`map.*`)는 정보보호팀만 접근한다.
