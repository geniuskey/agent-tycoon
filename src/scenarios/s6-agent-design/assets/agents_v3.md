## 항상 지킬 것
- "수율"이라고 쓰지 않는다. 라인 수율 / 검사 수율로 구분한다. → 위키: 지표 정의
- 저장 시각은 UTC. 보고서에는 KST(+9)로 표시한다.
- 11/10 이전 D07은 D07_LEGACY.
- 데이터는 수율 마트에서만 조회한다 (읽기 전용).

## 검토·회귀 시험에서 배운 것
{{#if kb.et12}}- 신규 설비는 MES 설비 마스터의 별칭으로만 매핑한다. **EQ-N2-ET12 = ETCH-12 = 2라인 12호기** (12/17 가동). 마스터에 없는 설비는 추측하지 말고 '확인 필요'.
{{/if}}{{#if kb.unknown_rule}}- 지식·데이터로 확인되지 않는 것은 추측하지 말고 **'확인 필요'**로 표시한다.
{{/if}}{{#if kb.hypo_rule}}- 불량 원인은 단정하지 않는다. 데이터로 뒷받침되는 **가설**과 확인할 담당자를 함께 쓴다.
{{/if}}{{#if kb.cause}}- D07 증가 시 CMP 슬러리는 '먼저 확인해 볼 것'이지 원인이 아니다 (이도윤, 12/29).
{{/if}}{{#if kb.yield}}- 검사 수율은 **재작업 웨이퍼 제외** (`rework_excluded`), 테스트 웨이퍼(T lot) 제외 — 마트 뷰 값을 그대로 쓴다.
{{/if}}{{#if kb.hr}}- 작업자 개인의 성과·평가는 보고서에 쓰지 않는다.
{{/if}}{{#if kb.utc}}- 로거 시각(UTC)은 반드시 KST로 바꿔 쓴다.
{{/if}}{{#if kb.skill_rule}}- 주간 보고는 **항상 `skills/weekly-report` 절차**로 작성한다 (재작업·테스트 웨이퍼 제외 규칙이 거기 있다).
{{/if}}{{#if kb.et13}}- **EQ-N2-ET13 = ETCH-13 = 2라인 13호기** (1/2 반입).
{{/if}}{{#if kb.cite_rule}}- 보고서의 모든 숫자에 출처(마트 뷰·컬럼)를 단다.
{{/if}}
